# securityqq.github.io

Alex Varga's personal site, served by GitHub Pages at https://securityqq.github.io.

This is a static port of the homepage of https://alexvarga.xyz (source of truth:
the [ai-twin](https://github.com/SecurityQQ/ai-twin) repo, deployed on Vercel).
No build step: a single self-contained `index.html` with inline CSS/JS.

Subpages — blog, CV, llms.txt, resume.json — link to alexvarga.xyz so there is
one canonical copy of the content. To update this site, re-port the homepage
from the ai-twin repo.
